# Portfólio Hexatombe

Portfólio estático em HTML, CSS, JavaScript e Bootstrap 5, com estética sombria inspirada no clima de Ordem Paranormal: Hexatombe. O visual, os símbolos e os textos gráficos são originais, sem utilizar artes oficiais.

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` com Live Server ou diretamente no navegador.

## Personalizações obrigatórias antes de entregar
- Troque `SEUEMAIL@EXEMPLO.COM` pelo seu e-mail.
- Troque `SEU-USUARIO` e `SEU-PERFIL` pelos links reais.
- Nos três projetos, substitua `href="#"` pelos links dos repositórios GitHub.
- Substitua o quadro com as iniciais GI por uma foto/avatar, se desejar.
- Confira se as descrições dos projetos correspondem às versões que você realmente publicou.

## Publicar
Envie a pasta para um repositório público no GitHub. Depois, importe esse repositório na Vercel como projeto estático. Não é necessário comando de build; a raiz do projeto é a própria pasta.

## Tecnologias
Bootstrap 5.3.3 (CDN), HTML5, CSS3 e JavaScript.
